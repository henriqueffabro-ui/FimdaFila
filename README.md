# Fim da Fila

Website de administração e reserva de lanches do CEEP

## Funcionalidades

- Cadastro e login
- Cadastrar lanche (somente administrador)
- Editar lanche (somente administrador)
- Visualizar vendas (somente administrador)
- Comprar lanche
- Visualizar compras

## Tecnologias

| Front | HTML, CSS, JS | 
| Back | PHP |
| Banco | MySQL / MariaDB |

- Importar o banco_fila.sql no software de banco de dados
- Ligar o servidor
- Rodar algum dos seguintes arquivos: home.html, login.php, singin.php
